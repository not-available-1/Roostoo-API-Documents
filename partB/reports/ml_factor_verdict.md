## 结论

1. **严格口径下，ML 没有自动入选任何新因子。** 8 个模型里有 5 个过了 IS 三道门槛，
   但每个都被最后两关挡住（见下表）。
2. **唯一"差一点"的是 `ml_bag`**：OOS 盲验 alpha +92.5%/年（t=4.16）、Bonferroni 过关，
   只在与手工因子 `lowvol_14d` 的去相关上超线 **0.017**（0.517 vs 0.5 上限）。
   按 R² 算约 27% 的方差是共享的——但这个相关系数的抽样标准误约 ±0.02~0.04，
   **统计上 0.517 和 0.5 分不开**。门槛照原样执行（理由见下），
   **要不要用它是 C 的取舍**——本文档把双方数据并排摆出来，B 不替你决定组合。
3. 真正有价值的副产品是**验证**：PCA 在完全没看过收益的情况下，无监督地重新发现了
   "低波动"和"动量"两根最强的轴（与手工因子相关 0.899 / 0.781），说明手工因子挖的是
   真结构，不是噪声拟合。这条对 C 的现有组合是加分项。

## 逐模型判决

口径：65 个可交易币、4h bar、预测期 6 根（1 天）、分割点 2026-01-01、IS 选 OOS 盲验、
walk-forward 逐季度重拟合、t 值已做 Newey-West 重叠修正、8 个模型 Bonferroni 校正后临界 t = 2.73。

| 模型 | IS alpha | OOS alpha（盲验） | 死因 |
|---|---|---|---|
| ml_bag | +129.5%/y (t 7.45) | **+92.5%/y (t 4.16)** | 与 lowvol_14d 相关 0.517，超去相关线 0.017 |
| ml_ridge | +102.8%/y | +91.8%/y (t 4.19) | 与 ml_bag 相关 0.941（同一信号的马甲）；与 lowvol 0.565 |
| ml_lasso | +89.2%/y | +101.9%/y (t 4.57) | 与 ml_bag 相关 0.944；且 Bonferroni 不过（NW t 2.63 < 2.73） |
| ml_pc2 | +51.3%/y | +95.9%/y (t 4.58) | **与 lowvol_14d 相关 −0.899**，就是 lowvol 本身；Bonferroni 不过（NW t 1.54） |
| ml_pc3 | +41.7%/y (t 2.14) | **−85.0%/y (t −3.88)** | **OOS 一票否决**：盲验段方向整个反过来。IS 过线是运气 |
| ml_pc5 | +60.3%/y | +88.0%/y (t 4.44) | IS 的 NW t 只有 1.91，过不了经济门槛；Bonferroni 不过 |
| ml_pc1 | −17.5%/y | +33.2%/y (t 1.48) | 三道门槛都没过；是"动量轴"（与 rangepos_14d 相关 0.781） |
| ml_pc4 | +9.7%/y | −10.8%/y | 全不过 |

四个死法对应四类问题：**马甲重复**（ridge/lasso/pc2）、**OOS 崩塌**（pc3）、
**多重检验下不够强**（lasso/pc5）、**信号本来就弱**（pc1/pc4）。
8 个模型全灭不是坏事——它说明门槛在起作用：任何一个看起来能赚钱的黑箱，都有一关
能把它拦下来。

### 0.517 这一刀为什么照原样切

ml_bag 与 lowvol_14d 的相关是 0.517，上限 0.5，超了 0.017。而这个 0.017 落在
抽样噪声里（相关系数的标准误约 ±0.02~0.04）——也就是说，**统计上根本分不出
它到底是 0.50 还是 0.52**。

那为什么不放宽？**门槛的价值在于它不看结果。** 0.5 这条线是在跑 ML 之前定的，
现在因为一个因子刚好压线就改线，等于让数据来挑规则——下一次压线的因子也会被
同样地放行，门槛就退化成"我想留谁就留谁"的事后说辞。

要改这条线，正确的做法是给出**一个在看到 0.517 这个数字之前就成立的论证**
（比如"65 个币 × 7 个季度的样本量下，0.5 这条线的假阴性率太高，应该按
抽样标准误放宽到 0.55"），并且写进流程、对之后所有因子一视同仁。
这条要求已经写进 `docs/handoff_to_researcher.md` §8 Q3，交给 researcher 独立判断。

**更该做的替代检验**：与其争论 0.517 算不算超线，不如直接测 ml_bag 的多空收益
对 lowvol_14d 的多空收益回归后的**残差 alpha**。这是同一个问题的经济学版本，
比相关系数更有判决力（相关只说"像不像"，残差 alpha 直接说"扣掉 lowvol 还剩多少钱"）。
目前做不了，因为 ML 因子面板只在 `ml_mine` 运行时存在于内存、没存盘；
补上存盘约需一次 15 分钟的重跑。

## ml_bag 的金融逻辑（如果 C 要用，先读这段）

### 归因第一步：为什么不能直接读权重表

**逐特征权重不是归因的正确单位。** ret 组里 `r_180` 和 `r_180_skip6` 相关接近 1，
共线组内的权重可以任意平移而模型预测值完全不变。实测：

```
w(r_180)       = -0.03277
w(r_180_skip6) = +0.03251
```

只读第二行会以为模型在**买 30 天动量**。但因为对数收益可加，有个精确恒等式
（`ml_features.py:88-92`，已用单测钉住）：

```
r_K        = log c_t - log c_{t-K}      = Σ_{k=1..K} e_k
r_K_skip6  = log c_{t-6} - log c_{t-K}  = Σ_{k=7..K} e_k
⟹ r_K - r_K_skip6 = r_6                 （精确，不是近似）
```

代入：净 30 天动量 = −0.03277 + 0.03251 = **−0.00026 ≈ 0**。两个大权重互相抵消，
剩下的是 −0.0328 的 **1 天反转**。归因叙事初版就此把机制量级排反了。

### 归因第二步：把所有权重摊到 horizon 上

`partB/ml_mine.py: increment_exposure()` 用上面这个恒等式，把每个特征的权重精确摊成
"往回数第 k 根 bar 的单根增量 e_k 上的净系数 c_k"。`rs_K`（相对 BTC 超额）走同一条
恒等式，单独算一条通道。以下是**跑出来的**结果，不是手推：

| horizon 带 | 本币通道 c_k（每根） | 超额通道（vs BTC） | 合计 | 读法 |
|---|---|---|---|---|
| **1 天**（lag 1-6） | −0.0893 | −0.0363 | **−0.1256** | 最近一天涨得多 → 做空它 |
| 2-7 天（lag 7-42） | +0.0079 | −0.0363 | −0.0284 | 反转延伸，弱 4 倍 |
| 7-15 天（lag 43-90） | +0.0275 | −0.0101 | +0.0174 | **唯一的动量段**，弱 7 倍 |
| 15-30 天（lag 91-180） | −0.0003 | 0.0000 | −0.0003 | 精确抵消，等于没押 |

逐根看更清楚（合计通道）：lag 1 = **−0.1377**、lag 2 = −0.1334、lag 3 = −0.1280、
lag 4-6 = −0.1181、lag 7 = **−0.0469**（掉一个数量级）、lag 43 起翻正。

### 归因结论：机制排序

| 排名 | 机制 | 证据 | 强度 |
|---|---|---|---|
| 1 | **低波动异象** | `rv_90 = −0.03926`（全表最大负权重）、`dvol_90 = −0.01971`；三条独立证据见下节 | 最强 |
| 2 | **1 天反转** | 合计通道 lag 1 = −0.1377，是第二大 lag 的近 4 倍；`r_3/r_6/r_12` 全负 | 次强 |
| 3 | **相对强弱反转** | `rs_42 = −0.02620`、`rs_90 = −0.01008`：跑赢 BTC 的币被做空 | 中 |
| 4 | **7-15 天动量** | 合计通道 lag 43-90 = +0.0174；`rangepos_90 = +0.02244`、`intrabar_18 = +0.01701` | 弱 |
| 5 | 流动性/量价 | `amihud_42 = +0.00979`、`pv_corr_90 = −0.00632` | 弱 |
| — | ~~30 天动量~~ | **净暴露 −0.0003 ≈ 0，模型没有在这个 horizon 上下注** | 无 |

**低波动这条有三重独立证据**（不是只看一个权重）：
① bag 的最大负权重是 `rv_90`；
② lasso 在最后一折只留下一个非零特征，也是 `rv_90`，符号为负；
③ 完全无监督的 PCA 第二主成分（只看特征协方差、从没见过收益）与手工因子
`lowvol_14d` 相关 **−0.899**。

**两个必须说清的修正**（初版归因写错了）：
- `pk_42`（峰值偏度）权重是 **+0.00005 ≈ 0**，不是负向驱动，初版把它列进"波动率负"是错的。
- `rv_180 = −0.00148`，只有 `rv_90` 的 **1/26**，不能和 rv_90 并列成"波动率双驱动"。
  波动率押注基本全在 90 根（15 天）这一个尺度上。

**一个还没解释的矛盾**：`rev_1d` 单独作为因子，IC_IR 排全表第 2，但多空组合年亏 37%；
而在 ml_bag 里反转却像是主要收益来源。合理解释是**交互作用**——ml_bag 同时压了波动率，
等于"只在高波动彩票币里做空近期涨幅"，这和"全市场无差别做空近期涨幅"是两件事。
但这条目前只是推测，没做过分组验证。

**给 C 的一句话**：ml_bag 实质是 **低波动 + 强 1 天反转**的混合体，动量含量很低
（7-15 天有一点，30 天为零）。若打算用它替换 `mom_30d_skip1d`，那是**用反转敞口换
动量敞口**，与替换的初衷相反——先做残差 alpha 检验再谈。

**ml_bag vs lowvol_14d 并排**（给 C 的取舍表）：

| | alpha_IS | alpha_OOS | beta_IS | 换手(每 bar) | 与 lowvol 相关 |
|---|---|---|---|---|---|
| lowvol_14d | +72.7%/y (t 4.09) | +101.6%/y (t 4.44) | −0.556 | 0.147 | 1.0 |
| ml_bag | +129.5%/y (t 7.45, NW 4.01) | +92.5%/y (t 4.16) | −0.425 | 0.314 | 0.517 |

解读（人话版）：
- 两者的 OOS 都在 +90~100%/年、t≈4.2，**旗鼓相当**，不是"ML 碾压手工"。
- 换手上 ml_bag 高一倍（0.314 vs 0.147），每 bar 的交易成本更高。
- 相关 0.517 = 一半像一半不像：像的那半是"低波动"，不像的那半是动量+反转+流动性。
- **beta 都是负的**（−0.43 / −0.56）：这两个因子本身就偏做空山寨市场。C 做 70-30
  净敞口时，如果两个都用，做空压力会叠加，必须合并算而不是各算各的。

**给 C 的三个事实**：
1. 你手上三个因子里，`mom_30d_skip1d` 的 OOS 是 **−68.7%/年（t −3.17）**——盲验段已经
   反向。ml_bag 与 mom 的相关只有 0.270，是最自然的替换候选，**但**按上面的归因，
   ml_bag 的动量含量很低、反转含量很高，这个替换换的不是同一种敞口。
2. 若 ml_bag 与 lowvol_14d 并用，总敞口的空头 beta 会加倍集中（两个都是 −0.4~−0.5），
   对冲市场 beta 的难度上升。
3. **超参稳定性要分开看**（初版这里写错了，把 ridge 的毛病安到了 bag 头上）：
   - `ml_bag` 的正则强度是**固定的** `bag_lam = 300`，不做逐折 CV，所以不存在 λ 抖动；
     它的训练样本逐折单调增长（19,150 → 229,527），最后一折是**最稳**的一折。
   - 真正不稳的是 `ml_ridge` / `ml_lasso`：CV 选出的 λ 逐折从 **5.6e3 抖到 3.2e6**
     （跨 3 个数量级），lasso 非零特征数从 **25 衰减到 1**。
   - 最后一折的测试段只有 **350 行**（OOS 尾巴短），这是评估样本少，不是训练样本少。
   - 实盘用的话仍建议每月重跑 `python -m partB.ml_mine`——但理由是特征分布会漂，
     不是 ml_bag 的参数不稳。

## PCA 的证词（为什么手工因子可信）

PCA 主成分是**无监督**的——它只看 62 个特征的协方差结构，从没见过任何收益数据。
结果：
- **ml_pc1** 载荷全在收益率/相对强弱上 → 与 `rangepos_14d`（手工动量类）相关 **0.781**
- **ml_pc2** 载荷全在波动率上 → 与 `lowvol_14d` 相关 **−0.899**

两条最强的横截面结构轴，被手工因子和 PCA 各自独立地找到了。这说明 C 现在用的
lowvol + rangepos 踩在真实的市场结构上，而不是挖数据挖出来的幻觉。

## 归因的一个已知局限

上面所有权重都来自**最后一折**（2026Q4）。`ml_mine.py` 内部逐折都算了权重，
但只把最后一折写进了 `ml_attribution_last_fold.csv`，所以**跨折符号一致率无法核验**
——即"rv_90 在 8 折里是不是都为负"这个最基本的稳健性问题，现在答不出来。
应补存全折权重（`ml_attribution_all_folds.csv`）并统计每个特征的符号一致率。
在那之前，归因结论的可信度要打折：它可能只是最后一折的局部现象。

## 结论汇总（一句话给 C）

**ML 没有产出"必须替换现有组合"的新东西**：它最强的一支（ml_bag）和 lowvol_14d
在 OOS 上打平、换手更高、相关 0.517 卡在去相关线上；它最弱的几支死得干净利落。
但它完成了三件事：

1. **确认现有手工因子挖到的是真结构**——完全无监督的 PCA 独立地重新找到了
   "低波动"（与 lowvol_14d 相关 −0.899）和"动量"（与 rangepos_14d 相关 0.781）两根轴。
2. **给出了 ml_bag 这个备胎，但要标清它是什么**——它是 **低波动 + 强 1 天反转**，
   **不是** mom_30d_skip1d 的同类替代品。数据已摆全，取舍归 C。
3. **一个硬教训**——OOS 一票否决挡掉了 ml_pc3 这颗 IS +41.7% / OOS **−85.0%** 的雷。
   IS 上勉强过线的因子，盲验段可以整个反向。

## 已修的 bug：`cs_standardize` 的退化截面判据

**症状**：横截面 z-score 之后，某个特征在某个 ts 上的均值不是 0 而是 0.95。

**根因**：原代码用 `sd = v.std(axis=1).replace(0, np.nan)` 挡"整个截面取值相同"的退化情况。
但**这个判据不够**：一整列完全相同的浮点数，pandas 算出的 std 不是精确的 0，而是 ~1e-14
（均值自身有舍入，`x - mean` 就不为 0）。于是 `噪声 / 噪声` 被放大成 O(1) 的数，
再被 `clip(-3, 3)` 截断——一个**毫无信息**的特征变成了满格强信号，而且完全静默。

**修法**：改成**相对**容差 `sd = sd.where(sd > 1e-10 * scale, np.nan)`，
`scale` 取该截面的 `abs().mean()`。这样 sd 为 0、为 NaN、或相对量级可忽略的，一律判退化。

**影响面实测**（真实数据，65 币 × 4392 根 4h bar × 75 特征 = 1734 万个格子）：
- sd 精确为 0（旧判据已正确处理）：126 个截面
- sd 非零但只是浮点噪声（旧判据漏掉）：**1 个截面**，出现在 `age_days`
- 而 `age_days` **当时根本没进模型**（`ml_attribution_last_fold.csv` 里没有这一行）

⟹ **对已交付的结果零影响，不需要重跑。** 但这是个埋着的雷：`ml_features.py` 里
`_feat_age` 的 docstring 已经写过同一类坑（"cumsum 会被个别缺失 bar 干扰，造成
'几乎相同但标准差不为 0'的伪截面"），说明它在特征层被绕开过一次，
但**标准化层的通用防线一直是缺的**。现在补上了。

**顺带修掉的测试缺陷**：原来的断言是 `X1.xs(X1.index.get_level_values("ts")[500], ...)`
——按**位置**挑一行来检查均值。位置 500 落在哪根 bar 上取决于特征数量和 NaN 分布，
特征池一改就换了一根 bar，测试于是**时过时不过**（本次就复现了）。
现在改成检查**全部**截面，并新增 `test_cs_standardize_kills_degenerate_cross_section`
专门钉住"整列相同必须变 NaN"这条。
