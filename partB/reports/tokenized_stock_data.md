# Tokenized Stock 数据报告（Binance 版）

**结论先说**: 21 个 tokenized stock 的历史数据源改成 **Binance Vision**，不再用 Yahoo。
理由是 Roostoo 的报价本来就是从 Binance 流过来的（FAQ Q17），代币本身在 Binance 现货上就有交易对，
一一对应、价格几乎相等。Yahoo 报的是**标的股票**，是另一个东西 —— 拿它当参照可以，当数据源是错的。

代价是历史很短：**最长 115 天，21 个里 0 个够 IS 窗口**。所以这批数据的用途被严格限定，见 §5。

数据日期 2026-10-05。

---

## 1. 符号映射：Roostoo ↔ Binance 是一对一的

规则极其简单，21 个全部命中，没有一个例外：

```
Roostoo  NVDAB/USD   ↔   Binance 现货  NVDABUSDT
即       {COIN}/USD  ↔   {COIN}USDT          （和 crypto 是同一条规则）
```

2026-10-04 实测（Roostoo `/v3/ticker` 最新价 vs Binance 最新 1h 收盘）：

| 交易对 | Roostoo | Binance | 差 |
|---|---|---|---|
| TSLAB/USD | 371.43 | 371.43 | **0bp** |
| NVDAB/USD | 234.69 | 234.57 | 5bp |
| MUB/USD | 1069.02 | 1069.32 | 0.3bp |
| SKHYB/USD | 195.25 | 194.96 | 15bp |
| CBRSB/USD | 180.64 | 180.25 | 22bp |
| CRCLB/USD | 83.28 | 83.09 | 23bp |

**这就是"数据源应该用谁"的答案**：Roostoo 跟的是 Binance 的代币，不是 Yahoo 的股票。

### 之前那个"SKHYB 差 7 倍"的悬案，破了

用 Yahoo 时看到 SKHYB 差 −8577bp（代币只有标的的 1/7），我当时怀疑代币脱钩。**错的**。
真相是参照物选错了：Yahoo 上 `000660.KS` 是 SK 海力士在**韩交所**的报价（KRW，15:30 KST = 06:30 UTC 收盘），
而 Roostoo/Binance 的 SKHYB 代币是 24/7 的美元计价代币，两者口径根本不同。
换成 Binance 之后 194.96 vs 195.25，差 15bp，问题消失。

## 3. 代币到底跟不跟标的？（115 天重叠期的检验）

这是唯一一个能实证回答的窗口：Binance 有代币价、Yahoo 有标的价，两边重叠 56~79 个交易日。

方法：取**同一时刻**（美股收盘，20:00 或 21:00 UTC）两边的价格。
代币取那根 1h bar 的 close，标的取当天日线 close（美股日线的时间戳就是收盘时刻）。
这样比的是同一个瞬间 —— 之前用 Yahoo 时犯的错是拿"周五收盘"去对"周日实时报价"，
中间隔着两天休市，量出来的"偏离"里全是时点错配，不是跟踪误差。

完整结果在 `stock_tracking_binance_vs_underlying.csv`。汇总：

### 20 个参照物在美股时段的交易对

| 指标 | 中位数 | 最差 | 怎么读 |
|---|---|---|---|
| 水平偏离 \|代币/标的 − 1\| | **8bp** | 54bp (QCOMB) | 代币几乎就是标的的 1:1 镜像，没有系统性折溢价 |
| 日收益相关 | **0.943** | 0.838 (PLTRB) | 涨跌高度同步 |
| 对标的 beta | **0.92** | 0.67 (PLTRB) | 幅度也接近 1:1 |
| 日跟踪误差 | **153bp** | 318bp (CBRSB) | 年化约 24%，见下面的解释 |
| 非美股时段贡献的绝对收益 | **50%** | — | 代币真的在 24/7 交易 |

**153bp 的日跟踪误差看着大，但大部分不是"脱钩"**，而是两件事：

1. **代币在美股休市时也在动**（占了一半的绝对收益）。周末消息、盘前盘后、亚洲时段的情绪，
   全都反映在代币价上，而 Yahoo 的日线只有一个收盘价、看不到这些。
   这不是噪声，这是**额外的可交易信息** —— 对我们反而是好事。
2. 代币有自己的供需（发行/赎回的摩擦、流动性薄），会有小幅溢价折价摆动。

水平偏离中位数只有 8bp 说明第 2 点的影响很小 —— 如果有持续脱钩，水平偏离会漂移，
而它稳定在 10bp 量级。

> 判定：**代币是标的的合格镜像**。用标的的长历史去构建收益率型因子在原理上站得住
> （我们所有因子都是收益率型的，对常数缩放不敏感）。但受 §2 的历史长度限制，
> 这条路现在**做不了正式的因子选择**。

### SKHYB/USD 单独说明：这一行的数字不可解读

检验结果里 SKHYB 是唯一的异常值（比值 0.137、收益相关 0.16、beta 0.14）。
**不能**据此说 SKHYB 代币脱钩了，原因是参照物本身有问题：

- 它的标的是韩股 `000660.KS`，06:30 UTC 收盘，和"美股收盘时刻"差 **13.5 小时** → 时点错配；
- Yahoo 那条序列换算成 USD 后约为代币的 7.3 倍 → 口径也不是 1:1（可能是份额比例，
  也可能是 FX/复权处理不一致，尚未查清）。

而代币本身完全正常：194.96 vs Roostoo 的 195.25，差 15bp。

代码里已经把它标成 `ref_us_hours=False` 并从汇总中剔除（`NON_US_REF`），
CSV 里照常保留这一行，但读的时候要知道它不能用来下结论。

## 4. 顺带解决了一个悬案：实盘怎么拿股票的 bar

之前的判断是"BarFeed 的源是 Binance，而 Binance 不上市股票，所以股票没有实盘 bar 方案"。
**这个判断建立在错误前提上** —— Binance 上市了全部 21 个。

所以 `roostoo_to_binance("NVDAB/USD") → NVDABUSDT` 直接可用，
`partB/live/barfeed.py` 的 warmup / 轮询 / 重启缓存恢复 / 质量校验 / 价差漂移监控
**一行代码都不用改**，股票和 crypto 走完全相同的路径。

## 5. 这批数据能干什么、不能干什么

| | 用途 | 说明 |
|---|---|---|
| ✅ | **实盘 bar 源** | BarFeed 原样可用，和 crypto 同一条路径 |
| ✅ | **短窗口描述性研究** | 2026-06 以来这一段，可以看波动、相关结构、和 crypto 的联动 |
| ✅ | **代币/标的跟踪检验** | 就是 §3，115 天是唯一能做的窗口，已经做完了 |
| ❌ | **和 crypto 同口径的因子选择** | 0/21 够 IS 窗口，没有样本外，做了也是自欺 |
| ❌ | **单独的 walk-forward 回测** | 83~115 天连两个季度都凑不齐 |

## 7. 给 C 的建议

1. **现阶段股票池不单独建策略**。115 天做不出可信的因子选择，硬做就是在给评委演示过拟合。
2. **但 BarFeed 已经能用**，所以如果 C 想把股票加进实盘宇宙（比如做一个"crypto + 股票"的
   横截面组合），管道是通的，缺的只是研究依据。加不加请 C 决定，B 侧不提供股票因子。
3. 如果要给股票建因子，**唯一诚实的做法**是用标的股票的长历史（Yahoo）构建收益率型因子，
   然后假设代币跟随标的（§3 已验证 20/21 成立）。这条路 B 可以走，但需要明确它多了一层假设，
   而且 SKHYB 必须排除或单独处理。要不要做，等 C 说。
4. 比赛只剩 10 天，我的建议是**先把 crypto 那边 ML 挖出来的因子落地**（见 `ml_selected.json`），
   股票池放到赛后。
